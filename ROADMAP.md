# Roadmap

Ideas for future versions, in no particular order. Tick an item and add it to CHANGELOG.md when it ships.

- [ ] Readiness monitors (mode 01 PID 01, bytes B–D): show which emissions self-tests have finished. Useful before a roadworthy test and after clearing codes.
- [ ] Mode 06 on-board test results (misfire counts per cylinder, catalyst and O2 sensor test values)
- [ ] Larger code library: more P2xxx and U-codes, plus manufacturer packs (VW, Toyota, Ford, Hyundai)
- [ ] Live-data graphs during a road test, with recording and CSV export
- [ ] Before/after report: compare the scan before and after a repair
- [ ] Workshop logo upload and custom report branding
- [ ] Repair cost estimate fields (parts + labour in ZAR) on each fault, totalled on the report
- [ ] Customer copy vs technician copy (simplified vs detailed report)
- [ ] Import a VCDS Auto-Scan text file and turn it into the same customer report (VW Group cars, all modules)
- [ ] Multi-module scanning (ABS, airbag, transmission) for adapters that support custom headers, such as OBDLink
- [ ] Installable app with offline support (PWA)
- [ ] Shareable report link or emailing a report to the customer
- [ ] Custom domain for the live site
